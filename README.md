# DRIPCASES

Площадка с кейсами одежды. MVP — первая фаза.

## Что работает

- Лендинг + каталог кейсов
- Регистрация / авторизация (email + пароль)
- Открытие кейсов (серверный крипто-рандом, анимация)
- Личный кабинет пользователя (баланс, история, заказы)
- Оформление получения товара (адрес доставки)
- Админ-панель: обзор, кейсы (CRUD + управление содержимым), товары, пользователи (пополнение баланса, блокировка), заказы (статусы, трек-номера)

## Стек

- Next.js 14 (App Router)
- PostgreSQL + Prisma
- NextAuth.js (Credentials)
- Tailwind CSS + Framer Motion
- TypeScript

## Запуск

```bash
# 1. Зависимости
npm install

# 2. Скопируй .env
cp .env.example .env
# Отредактируй DATABASE_URL и NEXTAUTH_SECRET

# 3. Генерация Prisma клиента + миграция
npx prisma generate
npx prisma db push

# 4. Сид (демо-данные)
npm run db:seed

# 5. Запуск
npm run dev
```

Откроется на http://localhost:3000

## Деплой

Render — конфиг в `render.yaml`, пошагово в `DEPLOY.md`.
Коротко: Blueprint → вписать `NEXTAUTH_URL` → передеплой → `npm run db:seed` в Shell.

## Рендеры витрин

Витрины — это картинки, а не CSS. Грузишь через админку
(`/admin/cases/<id>` → «Рендер витрины», drag-n-drop) или кладёшь
руками в `public/uploads/cases/`.

Полные требования к файлам — в `RENDERS.md`. Коротко: PNG с альфой, 4:5,
1200×1500+, без внешнего свечения и тени (их рисует CSS).

Пока рендеров нет — на их месте пунктирный плейсхолдер, вёрстка не ломается.
