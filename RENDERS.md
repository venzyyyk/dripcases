# Рендеры витрин — тех. требования

## Куда класть

Локально:
```
public/uploads/
  cases/      ← витрины кейсов
  products/   ← фото отдельных вещей
```

На Render — то же самое, но на персистентном диске `/var/data/uploads/`.
Переключается переменной `UPLOAD_DIR`, подробности в `DEPLOY.md`.

Загрузить можно двумя путями:
- **через админку** — `/admin/cases/<id>`, блок «Рендер витрины», drag-n-drop. Путь подставляется автоматически. После загрузки жми «Сохранить».
- **руками** — кинул файл в `public/uploads/cases/`, в том же блоке вписал путь `/uploads/cases/urban.png`, сохранил.

## Формат витрины

| Параметр | Значение |
|---|---|
| Формат | PNG с альфа-каналом (или WebP с альфой) |
| Пропорции | 4:5 вертикаль |
| Разрешение | 1200×1500 минимум, 1600×2000 под ретину |
| Вес | до 8 МБ (лимит аплоада), по факту целься в 300–600 КБ |
| Фон | **прозрачный** |

## Что должно быть в картинке

- стеклянный короб с одеждой внутри
- подиум/основание, на котором стоит короб
- собственные блики и рефлексы на стекле
- подсветка **внутри** короба

## Чего в картинке быть НЕ должно

- внешнее свечение вокруг витрины — оно рисуется CSS в `Vitrine`
- отражение/тень под подиумом — тоже CSS
- чёрный фон — только альфа

Если запечь свечение в картинку, на hover оно сложится со слоем CSS и будет пересвет.

## Компоновка внутри кадра

- витрина стоит на **нижней кромке** кадра — компонент выравнивает по `object-bottom`
- по бокам оставь ~6–8% воздуха, вплотную к краям не прижимай
- сверху воздуха больше, чем снизу — так читается «стоит на подиуме»

## Тёплые и холодные

На референсе PREMIUM и SUMMER подсвечены золотом, остальные — холодным белым.
Это влияет только на CSS-свечение, управляется в `src/app/page.tsx`:

```ts
const WARM_CASES = new Set(["PREMIUM", "SUMMER"]);
```

Сами рендеры делай в той же температуре, иначе картинка и свечение разойдутся.

## Фото товаров

Для товаров — те же правила, но:
- пропорции 1:1
- 800×800 достаточно
- одна вещь в кадре, прозрачный фон

## Пока рендеров нет

`Vitrine` рисует пунктирный плейсхолдер — сетка не разъезжается, можно верстать дальше.
Как только в поле `image` появляется путь, плейсхолдер заменяется на `next/image`
с правильными `sizes` и ленивой загрузкой (у первой витрины в герое — `priority`).
